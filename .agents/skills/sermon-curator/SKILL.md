# 대하설교 데이터 큐레이터 (Sermon Curator Skill)

이 스킬은 노우호 목사님의 샤론강단 대하설교(500여 편) 및 성경 66권 강해 녹취록 자료를 웹사이트에서 활용할 수 있는 구조화된 데이터로 변환하고 유지보수하기 위한 표준 절차를 안내합니다.

## 핵심 목표
1. HWP/텍스트 형태의 설교 녹취록에서 핵심 정보(번호, 제목, 본문 구절, 요약, 핵심 요점 3가지, 메시지) 추출.
2. `js/lecture_index.js` 및 `js/lecture_full_text.js` 규격에 맞는 무결점 JavaScript 객체 데이터 생성.
3. 성경 66권(구약 39권, 신약 27권) 및 장·절 분류와의 정합성 검증.

---

## 데이터 스키마 규격

### 1. `LECTURE_INDEX_DATA` 스키마 (`js/lecture_index.js`)

각 권(Book) 이름을 키(Key)로 하는 배열 형태로 작성합니다.

```javascript
LECTURE_INDEX_DATA["성경권명"] = [
  {
    no: "001", // 3자리 문자열 (예: "001", "045")
    title: "설교 제목",
    scripture: "성경 본문 구절 (예: 창세기 1장 1-5절)",
    file: "파일명.hwp", // H:\HDX\Church 로컬 연계용 원본 파일명
    summary: "설교의 핵심 흐름과 배경을 2~3문장으로 간결하게 요약한 설명",
    keyPoints: [
      "첫 번째 핵심 요점 (성경적 원리)",
      "두 번째 핵심 요점 (역사적·영적 배경)",
      "세 번째 핵심 요점 (삶의 적용)"
    ],
    message: "설교 전체를 관통하는 결론적 한 줄 메시지"
  }
];
```

### 2. `LECTURE_FULL_TEXT` 스키마 (`js/lecture_full_text.js`)

전문(Full-text) 보기가 지원되는 설교의 경우 번호(`no`)를 키로 사용합니다.

```javascript
LECTURE_FULL_TEXT["001"] = {
  title: "설교 제목",
  scripture: "성경 본문 구절",
  date: "설교 일자 또는 연도 (선택 사항)",
  content: `설교 본문 전문 텍스트 (단락 구분 및 줄바꿈 포함)`
};
```

## 데이터 가공 절차 (Step-by-Step)

1. **텍스트 분석 및 정제**:
   - 불필요한 줄바꿈, 스캔/OCR 오타 및 특수기호 정리.
   - 성경 본문 구절 표기를 한국어 개역개정 표준 표기법으로 통일 (예: `창 1:1` -> `창세기 1장 1절`).

2. **3대 핵심 요점(Key Points) 도출 기준**:
   - **Point 1 (성경적 맥락)**: 저작 배경, 당시 역사적 정황, 전후 문맥.
   - **Point 2 (에스라적 관점)**: 하나님의 심정(통곡), 인과관계, 성경 전체 구속사적 연결.
   - **Point 3 (실천적 메시지)**: 오늘날 성도가 취해야 할 구체적 순종과 회개.

3. **데이터 검증 체크리스트**:
   - `no` 번호가 중복되지 않고 3자리 형식인가?
   - `keyPoints`는 정확히 2~4개의 배열 원소로 이루어져 있는가?
   - 특수문자 따옴표(`"`, `'`)가 이스케이프되었거나 백틱(`` ` ``)을 적절히 사용했는가?
   - 웹 브라우저 콘솔에서 SyntaxError가 발생하지 않는지 확인.
