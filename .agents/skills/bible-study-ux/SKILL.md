# 성경 강해 웹 인터랙션 및 UX 스킬 (Bible Study UX Skill)

이 스킬은 성도들이 성경 66권 강좌와 대하설교를 집중해서 읽고 학습할 수 있도록 가독성, 학습 도구(퀴즈, 검색, 메모), 인터랙티브 UI를 설계하고 구현하는 가이드라인을 제공합니다.

---

## 1. 성경 골든벨 퀴즈 데이터 및 로직 (`js/quiz_data.js`)

각 권별 3~5개의 엄선된 신학·성경 지식 퀴즈를 제공합니다.

```javascript
BIBLE_QUIZ_DATA["창세기"] = [
  {
    q: "창세기에서 하나님께서 천지창조 후 첫 안식일에 하신 일과 의미는 무엇인가요?",
    options: [
      "피곤하셔서 쉬셨다",
      "창조 사역을 온전히 완성하시고 안식하시며 그 날을 복되게 하셨다",
      "천사들과 축제를 여셨다",
      "사람을 다시 창조하셨다"
    ],
    answer: 1, // 0-indexed
    explanation: "창세기 2장 2-3절: 하나님이 그가 하시던 일을 일곱째 날에 마치시니..."
  }
];
```

### 퀴즈 인터랙션 규칙
- 정답 선택 시 즉각적인 시각 피드백 (초록색 성공 테두리, 오답 시 빨간색 표시 및 정답 안내).
- 해설(`explanation`) 블록을 통한 성경 말씀 보충 학습 유도.
- 성경 골든벨 모드 (전 권 퀴즈 랜덤 출제 및 점수 집계 기능 연계).

---

## 2. 가독성 및 본문 뷰어 가이드라인

1. **폰트 및 행간 최적화**:
   - 한글 본문 가독성을 위해 `Pretendard`, `Noto Sans KR`, 또는 명조 계열 폰트 스택 적용.
   - `line-height: 1.8~2.0` 및 `letter-spacing: -0.02em` 적용으로 장문 설교 통독 시 피로도 최소화.
   - 사용자 맞춤 폰트 크기 조절기(A- / A+) 상태를 `localStorage`에 영구 저장.

2. **다크모드/라이트모드 일관성**:
   - `data-theme="dark"` 속성을 `<html>` 태그에 적용.
   - 배경: `bg-slate-900` / 카드: `bg-slate-800` / 텍스트: `text-slate-100` 및 `text-slate-300`.
   - 하이라이트 색상: 에스라 골드(`amber-500`, `amber-600`) 유지.

3. **고속 검색 및 필터링**:
   - 성경 권명(예: "창세기", "마태복음") 및 축약어(예: "창", "마") 매칭.
   - 설교 제목, 본문 구절, 핵심 요점 전문 검색.
   - 실시간 필터링 디바운스(Debounce: 150~200ms)로 부드러운 UI 반응성 유지.
